# Pink OSINT — Всё в одном месте

Платформа для OSINT-исследований. Полностью самодостаточная. Никаких внешних сервисов. Все инструменты встроены. Данные автоматически распределяются по веткам проектов.

## Что внутри

### Инструменты (всё встроено, не нужно уходить на другие сайты)

| Инструмент | Что делает |
|-----------|------------|
| **Google Dorking** | Поиск через дорки, 500+ готовых шаблонов, конструктор дорков, обход капчи, ротация прокси и User-Agent |
| **DNS-разведка** | A, AAAA, MX, NS, TXT, CNAME, SOA, SRV, PTR, SPF, DKIM, DMARC. Поиск поддоменов, обратный резолв, зонный трансфер |
| **WHOIS-поиск** | WHOIS доменов и IP, массовый WHOIS, история, парсер контактов, поиск доменов по email владельца |
| **Email-охота** | Поиск email по домену, по имени/фамилии, валидация через SMTP, поиск в GitHub и SSL-сертификатах |
| **Проверка утечек** | Поиск email/паролей/доменов в утечках, загрузка своих баз, мониторинг новых утечек, шифрование AES-256 |
| **Shodan** | Поиск по IP/домену/CIDR, баннерам, портам, CVE. Сравнение снимков |
| **Wayback Machine** | История URL, просмотр снимков, сравнение версий, поиск скрытых файлов |
| **Поиск людей** | Поиск по имени/фамилии/городу/телефону/никнейму. Профили в соцсетях. Связи между людьми |
| **Метаданные** | EXIF из фото, метаданные PDF/DOCX/XLSX/PPTX, GPS-координаты на карте, очистка метаданных |
| **Геолокация** | Определение по IP (встроенная GeoIP), карта OpenStreetMap, поиск ближайших объектов |

### Ветки проектов (автоматическая организация)

Создаёшь проект. Внутри — ветки. Каждая ветка — отдельное направление расследования.

**Как работают ветки:**
- Запускаешь любое сканирование
- Найденные данные автоматически классифицируются (email, телефон, IP, домен, пароль, геолокация, соцсети)
- Каждый тип данных попадает в нужную ветку сам
- Ничего не нужно сортировать вручную
